# Reed's Auto Detailing

Responsive website concept for Reed's Auto Detailing in Van Meter, Iowa.

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS 4

## Run locally

```bash
npm install
npm run dev
```

## Customize

Most business details are centralized in `src/data/site.ts`, including contact information, services, pricing placeholders, reviews, service area, hours, and before/after result slots.

Replace placeholder content with verified business information before publishing. Real detailing photos can be added under `public/results/` and referenced from `src/data/site.ts`.

## Build

```bash
npm run build
```
